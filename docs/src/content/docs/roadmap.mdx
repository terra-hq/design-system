Nothing on this page exists in the package yet. It is the agreed plan for version 0.2.0, and the [search](/search/) tags these classes as proposed.

## states

State lives in the class name, with no colons: `u--hover-background-d`, `u--focus-ring`, `u--active-scale-95`, `u--disabled-opacity-50`, and `u--group` with `u--group-hover-*` for children of a hovered parent. Hover only applies on devices that can hover. States have no breakpoint variants.

## motion

Transitions reuse Terra's time tokens (`u--duration-a/b/c` = 0.1s, 0.3s, 0.6s) and easing curves. Animations are utilities, not foundations: `u--animation-fade-in`, `fade-up`, `spin`, `pulse`. All of them respect `prefers-reduced-motion`.

## also planned

Opacity steps, cursor and pointer-events utilities, configurable breakpoints, and `f--background-*` beyond `e`.
