## how it behaves from desktop to mobile

There is **one breakpoint**: 810px (`tablets`). Above it every class uses its desktop size. At 810px and below, `f--font-a` to `f--font-d` switch to a smaller size. `f--font-e` and `f--font-f` stay the same everywhere. There is no separate step for phones: a 390px screen gets the same sizes as an 810px one.

| Class | Desktop (above 810px) | Tablet and mobile (810px and below) | Line height | Weight |
|---|---|---|---|---|
| `f--font-a` | 80px | 64px | 1.1 | 400 |
| `f--font-b` | 56px | 40px | 1.3 | 400 |
| `f--font-c` | 32px | 26px | 1.3 | 400 |
| `f--font-d` | 24px | 20px | 1.4 | 400 |
| `f--font-e` | 16px | 16px (no change) | 1.4 | 400 |
| `f--font-f` | 12px | 12px (no change) | 1.4 | 400 |

Drag the slider, or use the presets, to see the real classes change. The sizes next to each sample are read from the browser, not typed in.

To change only the weight, add a utility: `f--font-c u--font-bold`. The utility wins because it loads later.

<p class="f--font-e" style="margin:0">f--font-e, body text</p>
