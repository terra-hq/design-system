| Class | Value | Use |
|---|---|---|
| `f--radius-a` | 8px | Menu items |
| `f--radius-b` | 12px | Inputs, code blocks |
| `f--radius-c` | 16px | Cards, menus |
| `f--radius-d` | 20px | Modals |
| `f--radius-full` | 999px | Buttons, pills |
| `f--radius-round` | 50% | Avatars |
| `f--shadow-a` | float-sm | Toasts, tooltips |
| `f--shadow-b` | float-md | Menus |
| `f--shadow-c` | float-lg | Modals |

Cards don't get a shadow: they are separated with a border. Shadows are only for things that float.
