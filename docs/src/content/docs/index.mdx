## use the css

```html
<link rel="stylesheet" href="https://unpkg.com/@terrahq/design-system@latest/dist/style.css">
```

## two layers

| Layer | What it is | Example |
|---|---|---|
| `f--` foundation | Terra's design decisions: several properties per class, responsive included. They don't change. | `f--font-c`, `f--color-a`, `f--radius-c` |
| `u--` utilities | One property per class, with a variant per breakpoint. | `u--p-4`, `u--p-mobile-2`, `u--display-flex` |
